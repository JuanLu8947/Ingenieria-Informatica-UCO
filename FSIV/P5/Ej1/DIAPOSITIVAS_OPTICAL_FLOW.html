🌊 ¿Qué es el Flujo Óptico?

Definición

Es un campo vectorial que describe el movimiento aparente de píxeles entre frames consecutivos de un vídeo.

Ecuación de Flujo Óptico:
I(x,y,t) = I(x+dx, y+dy, t+dt)

Donde (dx,dy) es el vector de movimiento

Flujo Escaso

Calcula vectores solo en
puntos característicos
(esquinas, bordes)

Flujo Denso

Calcula vectores para
TODOS los píxeles
de la imagen

🔧 Algoritmo de Farneback

¿Por qué Farneback?

  • Cálculo de flujo óptico denso
  • Basado en aproximación polinómica local
  • Robusto ante ruido y cambios de iluminación
  • Implementación eficiente en OpenCV

Mi Implementación

// Crear algoritmo una sola vez (estático)
static cv::Ptr<cv::FarnebackOpticalFlow> alg;
if (alg.empty()) {
    alg = cv::FarnebackOpticalFlow::create();
}

// Configurar flag de estimación inicial
if (!flow.empty()) {
    alg->setFlags(OPTFLOW_USE_INITIAL_FLOW);
}

// Calcular flujo óptico
alg->calc(prev, next, flow);

⚙️ Pipeline Completo

1. Cálculo del Flujo Óptico

Usar algoritmo Farneback entre frame anterior y actual

2. Magnitud del Flujo

Calcular sqrt(vx² + vy²) para cada píxel

3. Umbralización

Crear máscara binaria: píxeles con magnitud ≥ threshold

4. Post-procesado

Dilatación morfológica + memoria temporal

5. Desenfoque Selectivo

Aplicar blur solo al fondo usando la máscara

🎯 Parámetro: THRESHOLD (th)

Control de Sensibilidad

Determina qué magnitud de flujo óptico se considera como "movimiento significativo"

  • th bajo (0.5-1.0): Detecta movimientos sutiles → Más píxeles como foreground
  • th medio (2.0-3.0): Equilibrio entre sensibilidad y estabilidad
  • th alto (5.0-10.0): Solo movimientos muy evidentes → Menos ruido
Demo: Mover trackbar de Threshold y observar cambios en la máscara

Implementación

cv::threshold(magnitud, mask, th, 255, cv::THRESH_BINARY);

🧠 Parámetro: ALPHA (Memoria)

Estabilización Temporal

Controla cuánta "memoria" tiene el sistema de las máscaras anteriores

nueva_mask = α × mask_anterior + (1-α) × mask_actual
  • α = 0.0: Sin memoria → máscara completamente nueva cada frame
  • α = 0.2-0.3: Memoria moderada → suaviza fluctuaciones
  • α = 0.8-0.9: Mucha memoria → máscara muy estable pero lenta
Efecto: Reduce parpadeo de la máscara y estabiliza la detección

🌫️ Tipos de Desenfoque

Box Blur (tipo 0)

Promedio simple en ventana cuadrada

Ventajas: Muy rápido
Efecto: Desenfoque uniforme

Gaussian Blur (tipo 1)

Ponderación gaussiana

Ventajas: Más natural
Efecto: Desenfoque suave

Radio de Desenfoque

Controla la intensidad del efecto:

  • Radio 1-3: Desenfoque sutil
  • Radio 5-10: Desenfoque moderado
  • Radio >15: Desenfoque muy intenso

Kernel Size = 2 × radio + 1
