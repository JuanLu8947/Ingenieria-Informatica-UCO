🎯 ¿Qué es la detección de bordes?

Fundamento teórico

Un borde es la localización de una frontera entre distintas áreas de la imagen (ej: cielo/montañas, nieve/raquetas).

El gradiente lumínico permite detectar estas fronteras: valores altos en zonas de transición, valores bajos en áreas constantes.

Gradiente: ∇I = [Δx, Δy]
Magnitud: G = √(Δx² + Δy²)

Pipeline completo:

1. Si g_r > 0: Filtro Gaussiano (tamaño 2r+1) para atenuar ruido y controlar escala
2. Derivadas parciales Δx, Δy con filtro de Sobel (apertura s_ap)
3. Magnitud del gradiente G = √(Δx² + Δy²)
4. Umbralización con detector seleccionado (Percentil / Otsu / Canny)
5. Thinning opcional para adelgazar bordes (Percentil/Otsu)

🔧 Detectores Implementados

1. Detector Percentil

Calcula histograma de |∇I| y usa percentil como umbral

if |∇I|(x,y) ≥ percentil_th → borde

2. Detector Otsu

Encuentra automáticamente el umbral que minimiza varianza intra-clase

umbral = argmin(σ²_within_class)

3. Detector Canny

Supresión de no-máximos + histéresis iterativa con doble umbral

"no-borde seguro" < th1, "dudoso" ∈ [th1,th2], "borde seguro" > th2

Los dudosos con ocho-vecino "borde" → clasificados como "borde". Proceso iterativo en cascada.

Ventaja de Canny: Mantiene conectividad mediante histéresis iterativa + mejor localización por supresión direccional

⚙️ Parámetro G_R (Gaussian Radius)

Control de escala y ruido

Filtro Gaussiano con kernel de tamaño 2*g_r+1

🔍 G_R = 0 (Sin filtro)

  • Detecta detalles muy finos
  • Mucho ruido - Sobel muy sensible
  • Bordes discontinuos y fragmentados

🎯 G_R = 1-3 (Óptimo)

  • Atenúa ruido eficazmente
  • Bordes principales nítidos
  • Balance ruido/detalle/escala

🌐 G_R = 5-8 (Mayor escala)

  • Solo estructuras grandes
  • Mayor robustez al ruido
  • Pérdida de detalles finos y texturas

💡 Trade-offs

  • Ruido: Mayor sigma (g_r) → Mayor robustez
  • Escala: Mayor sigma → Mayor extensión espacial
  • Detalles: Mayor sigma → Menor precisión

📐 Parámetro S_AP (Sobel Aperture)

Tamaño del kernel de derivadas

Controla el soporte espacial: s_ap → kernel_size = 2*s_ap+1

S_AP = 0: Kernel 1×1

Diferencias entre píxeles adyacentes • Muy sensible • Bordes muy finos

S_AP = 1: Kernel 3×3 (Estándar)

Equilibrio óptimo • Más robusto al ruido • Estándar en la industria

S_AP = 2-3: Kernels 5×5, 7×7

Derivadas más suaves • Menor precisión espacial • Máxima robustez

Trade-off: Kernel pequeño = mayor precisión, más ruido
Trade-off: Kernel grande = mayor robustez, menor precisión

🎛️ Parámetros de Umbralización

TH2 - Percentil/Canny Alto (60-95%)

  • 60%: Muchos píxeles como borde
  • 80%: Equilibrio típico
  • 95%: Solo gradientes muy altos

TH1 - Canny Bajo (10-40%)

Controla conectividad en histéresis de Canny

  • TH1 bajo: Más píxeles dudosos, bordes extendidos
  • TH1 alto: Menos conexiones, bordes fragmentados

Proceso de histéresis (Canny) - ITERATIVO

1. Píxeles > TH2: BORDE SEGURO
2. Píxeles < TH1: NO-BORDE SEGURO
3. Píxeles ∈ [TH1,TH2]: DUDOSO
4. Iteración: Dudoso con ocho-vecino "borde" → BORDE (arrastra en cascada)
5. Cuando termina: Dudosos restantes → NO BORDE

✂️ Algoritmo de Thinning

Adelgazamiento de bordes

Problema: Percentil y Otsu producen bordes gruesos vs Canny (1 píxel). Idealmente un borde debe tener 1 píxel de ancho.

Canny usa supresión de no-máximos (direccional, perpendicular al gradiente). Percentil/Otsu NO lo usan.

Mi implementación: Distance Transform

1. cv::distanceTransform(L2, kernel_5) → cada píxel blanco = distancia al negro más próximo
2. cv::dilate(dist, kernel_3x3) → cada píxel = máximo de su vecindad
3. máscara = (TF == TF_dilatada) → píxeles que son máximos locales 3×3
4. thinned = edges ∩ máscara → filtra píxeles no-máximos

❌ Sin Thinning

  • Percentil/Otsu: 3-5 píxeles ancho
  • Canny: 1 píxel ancho
  • Comparación injusta

✅ Con Thinning

  • Percentil/Otsu: hasta 2 píxeles ancho
  • Comparación más justa
  • Canny sigue superior (supresión direccional)
Limitación: Método menos efectivo que Zhang-Suen pero más simple. No requiere módulo extra ximageproc. Thinning omnidireccional vs supresión direccional de Canny.

📊 Métricas de Evaluación

Sensibilidad (Recall): TP/(TP+FN)
Precisión: TP/(TP+FP)
F1-Score: 2×(P×R)/(P+R)

Ground Truth desde consenso

Imagen de consenso C: SUMA de las GT de múltiples expertos

Normalizar MIN-MAX al rango (0%, 100%)

Generar GT umbralizada: GT = C >= c donde 'c' es % mínimo de consenso

Mayor 'c' → mayor acuerdo requerido entre expertos (GT más estricto)

Matriz de Confusión 2×2

Filas: Ground Truth | Columnas: Predicción

                   Pred:  
               Edge  No-Edge
GT: Edge    |   TP   |   FN   |
    No-Edge |   FP   |   TN   |

TP=borde detectado, FN=borde perdido, FP=falso positivo, TN=correcto negativo
