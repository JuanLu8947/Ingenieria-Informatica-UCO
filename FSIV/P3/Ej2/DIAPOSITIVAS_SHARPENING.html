🎯 ¿Qué es el Sharpening?

Filtros de Realce de Imágenes

Técnica que mejora la nitidez y definición de los detalles mediante la detección y amplificación de bordes.

Descomposición de la imagen:
I = I_l + I_h
(I = imagen original, I_l = componente suave,
I_h = detalles/bordes)

Técnica de realce:
O = I + I_h
(O = imagen realzada, añadimos más detalles a la original)

Usando Laplaciano:
I_h ≈ -∇²I
(∇² = operador Laplaciano, detecta cambios bruscos)
O = I + (-∇²I) = ([1] + (-∇²)) * I
([1] = filtro impulso: todos valores = 0 salvo centro = 1.0)
((-∇²) = Laplaciano negativo que realza bordes)

🔧 Tipos de Filtros Implementados

1. Laplaciano de 4 Vecinos

[0 1 0]
[1 -4 1]
[0 1 0]

Detecta bordes horizontales y verticales principalmente

2. Laplaciano de 8 Vecinos

[1 1 1]
[1 -8 1]
[1 1 1]

Detecta bordes en todas las direcciones, incluyendo diagonales

Filtros de Enfoque Correspondientes

4-vecinos: 8-vecinos:
[ 0 -1 0] [ 0 -1 0]
[-1 5 -1] [-1 9 -1]
[ 0 -1 0] [ 0 -1 0]

Construcción: S = [1] + (-∇²)
• S: filtro de sharpening
• [1] = filtro impulso unitario: matriz 3×3 con todos valores = 0 salvo centro = 1.0
• (-∇²) = Laplaciano negativo (añade contraste en bordes)
• Valores centrales: 5 = 1+4, 9 = 1+8

3. DoG (Difference of Gaussians)

∇² ≈ DoG(σ₁,σ₂) = G_σ₂ - G_σ₁
(G_σ = filtro Gaussiano con desviación σ)
donde σ₁ < σ₂ (σ₁ = radio pequeño, σ₂ = radio grande)

Filtro enfoque: S = [1] + (-DoG)
(S = filtro de sharpening final)

Aproxima el Laplaciano usando diferencia de Gaussianos

⚙️ Construcción del Filtro de Realce

Proceso de Construcción

  1. Seleccionar filtro base: Laplaciano 4/8 o DoG
  2. Invertir signo: Filtro_negativo = -Filtro_base
  3. Añadir impulso: Filtro_negativo[centro] += 1.0
Filtro_realce = -Laplaciano + δ(impulso_central)

¿Por qué funciona?

• El Laplaciano negativo invierte la detección de bordes
• El impulso central preserva la imagen original
• El resultado realza bordes manteniendo el contenido base

🎛️ Parámetros de Control

FILTER (Tipo de Filtro)

  • 0: Laplaciano 4-vecinos (bordes cardinales)
  • 1: Laplaciano 8-vecinos (todos los bordes)
  • 2: DoG (control multi-escala)

R1 y R2 (Solo para DoG)

Controlan los radios de los filtros gaussianos

  • R1 pequeño, R2 grande: Realce suave, menos ruido
  • R1 y R2 cercanos: Realce localizado, más detalles

CIRC (Modo de Bordes)

  • 0: Expansión con ceros (relleno negro)
  • 1: Expansión circular (imagen envuelta)

📈 Efectos al Variar Parámetros

Impacto del Tipo de Filtro

  • LAP4: Realce suave, bordes principales
  • LAP8: Realce intenso, todos los detalles
  • DoG: Realce controlable, menos artefactos

Impacto de los Radios (DoG)

  • R1↓, R2↑: Realce global, suave
  • R1↑, R2↓: Realce local, detalles finos
  • Diferencia grande: Más contraste
  • Diferencia pequeña: Efecto sutil

Impacto del Modo Circular

  • CIRC=0: Pueden aparecer artefactos en bordes
  • CIRC=1: Eliminación de artefactos, posibles discontinuidades
