🎯 ¿Qué es CLAHE?

Contrast Limited Adaptive Histogram Equalization

Técnica avanzada de mejora de contraste que combina procesamiento local con limitación de contraste para evitar la amplificación excesiva del ruido.

Ecualización Global

Una función de transformación para toda la imagen

✅ Simple

❌ Poco natural

Ecualización Local

Función diferente para cada ventana

✅ Adaptativa

❌ Amplifica ruido

CLAHE

Local + limitación de contraste

✅ Adaptativa

✅ Controla ruido

📊 Fundamento Matemático

Función de Transformación

O(x,y) = 255 × T[I(x,y)]

Donde:
I(x,y) = intensidad del píxel de entrada en posición (x,y)
O(x,y) = intensidad del píxel de salida en posición (x,y)
T = función de transformación obtenida del histograma normalizado y acumulado

Proceso CLAHE:

  1. Dividir imagen en ventanas de tamaño (2r+1, 2r+1)
  2. Para cada ventana:
    • Calcular histograma local
    • Aplicar limitación de contraste (si s ≥ 1)
    • Normalizar (L1 = 1.0)
    • Acumular histograma
    • Crear tabla de transformación
  3. Transformar solo el píxel central de cada ventana

🔒 Limitación de Contraste

¿Por qué es necesaria?

En zonas homogéneas, la ecualización local puede amplificar demasiado el ruido al intentar crear contraste donde no lo hay.

Nivel de recorte deseado:
CL = s × área(histograma) / bins(histograma)

Donde:
CL = Clipping Level (nivel máximo permitido por bin)
s = Slope Factor (parámetro de limitación de contraste)
área(histograma) = número total de píxeles en la ventana
bins(histograma) = número de contenedores del histograma (256 para 8 bits)

Problema y Solución:

❌ Problema

Si recortamos en CL y redistribuimos, el histograma final > CL

✅ Solución

Buscar valor P tal que: CL = P + R/bins(hist)
donde R es el área residual

🔍 Algoritmo de Búsqueda Binaria

Mi implementación en fsiv_compute_actual_clipping_histogram_value:

CL = s * área(histograma) / 256
top = CL
bottom = 0.0

while ((top - bottom) > 1.0):
    middle = (top + bottom) / 2
    R = 0.0
    for i in range(256):
        if histogram[i] > middle:
            R += histogram[i] - middle
    
    if R > ((CL - middle) * 256):
        top = middle
    else:
        bottom = middle

return bottom  // valor P efectivo
Resultado: Encuentra el valor P óptimo para recortar el histograma

🎛️ Parámetros de Control

S (Slope Factor) - Factor de Pendiente

  • s < 1.0: Sin limitación → ecualización clásica
  • s ∈ [3, 6]: Rango recomendado → buen balance
  • s > 6: Limitación muy fuerte → imagen muy suave

R (Radio) - Tamaño de Ventana

  • r = 0: Procesado global → una sola función
  • r = 1-2: Ventana pequeña → alta adaptabilidad
  • r = 3-4: Ventana media → equilibrio óptimo
  • r > 5: Ventana grande → suavizado local
Tamaño de ventana = (2^R + 1) × (2^R + 1) píxeles
