He realizado todas las funcionalidades de forma total, implementando:

- **Función `fsiv_combine_images`**: Implementada para combinar imagen de primer plano y fondo usando una máscara.

- **Parámetros ajustables**:

  - **Sensitivity (Sensibilidad)**: Tolerancia en la detección del color (0-100)
- **Soporte para múltiples formatos**: Imágenes estáticas, vídeo y cámara web.
